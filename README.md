**Song recommendation with LLMs.**

Turn your Spotify taste into an explorable music map, then discover new songs that match the tracks and vibes you already love.

## Access

Spotify limits access to approved users while the app is in development mode. To log into the website, send me the email address associated with your Spotify account so I can add you. Alternatively, create your own Spotify API credentials in the [Spotify Developer Dashboard](https://developer.spotify.com/dashboard).
